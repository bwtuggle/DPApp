# Bellevue Demographic Profile (static version)

A plain HTML/JS version of the Shiny dashboard. No R or server is needed to view it.

- `index.html` – the whole dashboard (tabs, map, charts). Tab links work, e.g. `index.html#quick-facts`.
- `data/` – chart JSON, tract GeoJSON, quick-facts table (generated by `export_data.R`).
- `lib/` – bundled Plotly.js 2.25.2 (same version as the R app), Leaflet 1.9.4 and MapLibre GL 4.7.1. No CDN needed.
- Basemap: OpenFreeMap "Positron" (open source, no API key), loaded from tiles.openfreemap.org.

## Hosting
Any static host works: copy the folder to the city web server, or push it to GitHub and enable Pages
(`.github/workflows/pages.yml` is included). Must be served over http(s); opening index.html straight
from disk will not load the data files.

## Updating data
Re-run `Rscript export_data.R DPAppData.RData` in this folder, then re-publish.

## Embedding
`<iframe src="https://YOUR-HOST/path/" title="Bellevue Demographic Profile" style="width:100%;height:900px;border:0"></iframe>`
